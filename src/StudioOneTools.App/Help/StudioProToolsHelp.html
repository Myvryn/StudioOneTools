🎛️ Overview

Studio Pro Tools is a portable utility suite for PreSonus Studio One producers. All six tools launch from the home screen and can run side by side.

The Six Tools

  • Song Archiver Blue
    Analyses a song folder, identifies used and unused audio files, and packages everything into a tidy ZIP archive with an HTML inventory report.
  • Un-Archiver Blue
    Restores a song from an archive ZIP — extracts the files, creates the song folder, and automatically fixes all internal paths so Studio One can open it immediately.
  • Folder Sweeper Orange
    Scans a root directory and flags song subfolders that look incomplete, stale, or empty, so you can safely delete them in bulk.
  • Song Backup Green
    Synchronises selected song folders to a backup location, copying only new or changed files so each run is fast.
  • Song ReNamer Purple
    Renames the entire song package in one step — folder, .song files, Mixdown/Master audio, and internal file references.
  • Path Fixer Teal
    Detects and corrects broken internal file paths inside a .song file after it has been moved or restored to a different location.
Studio Pro Tools is a single portable .exe — no installation needed. Just run it and pick a tool from the home screen.

🗂️ Song Archiver

Analyses a Studio One song folder and creates a ZIP archive containing only the files your song actually uses, plus an HTML report of every plugin, channel, and media file.

  1. Select the song folder

    Click Browse or paste the full path into the "Song folder" field. The folder should directly contain the .song file — not a parent directory. Analysis starts automatically after a short delay. If the folder contains more than one song file, a dialog will ask which one to use.

  2. Review the analysis results

    The panel shows the song name, count of used and unused WAV files, any issues (such as missing referenced audio), and a preview file if one exists. The media grid lists every file with columns for play, filename, path, used status, disk presence, and use count.

  3. Optionally play back audio files

    Click ▶ on any WAV row to hear that file. A progress bar fills as it plays. Starting a new file stops the previous one.

  4. Choose archive options
    • Retain Mixdown files — include the Mixdown folder in the archive
    • Retain Master files — include the Master folder in the archive
    • Set the archive destination using the Save As button
  5. Create the archive

    Click Create Archive. When complete, a dialog offers:

    • Include unused media files in the archive (excluded by default)
    • Remove from Studio One Recent Documents (default: on) — removes the song from Studio One's recent file list
    • Delete the original song folder
    • Open the archive folder in Explorer
  6. Review the HTML report

    Open Song_Information.html from inside the ZIP to see the full metadata, plugin list, channel map, and media inventory.

Enable Debug Mode in Settings to include XML schema discovery reports and raw XML files inside the archive — useful for diagnosing unexpected analysis results.
If any referenced audio files are missing from disk, archiving is blocked until the files are located or relinked inside Studio One.

📦 Un-Archiver

Restores a song from a ZIP archive created by Song Archiver. Extracts the files to a new folder and automatically fixes internal paths so Studio One can open the song immediately without relinking any media.

  1. Select the archive file

    Click Browse next to "Archive file" and choose a .zip created by Song Archiver. The archive name becomes the name of the restored song folder.

  2. Choose a destination folder

    Click Browse next to "Destination" and select (or create) the folder where the song will be placed. Defaults to your configured Default Song Folder. The "Will extract to" preview shows the exact path that will be created.

  3. Click Extract & Fix Paths

    The tool will:

    • Create a new subfolder named after the archive
    • Extract all files from the ZIP into that subfolder
    • Run Path Fixer automatically on the extracted .song file
  4. Done

    A summary reports how many internal paths were corrected. Click Yes when prompted to open the extracted folder in Explorer.

The Un-Archiver will not overwrite an existing folder. If a folder with the same name already exists at the destination, choose a different destination or rename the existing folder first.
After extraction, open the song in Studio One normally — all media files will be found automatically because the paths have already been corrected.

🧹 Folder Sweeper

Scans a root folder for song subfolders that look incomplete or stale, and lets you delete them safely in bulk.

  1. Select a root folder

    The root folder is pre-populated from your Default Song Folder setting and scanning begins automatically when the window opens — no button click required. You can also click Browse to choose a different folder.

  2. Review flagged folders

    Each row shows the folder name, the reason it was flagged, and its full path. Folders are flagged for any of these reasons:

    • No .song file found — folder contains no Studio One project
    • No Mixdown or Master folder — project was never exported
    • Song not modified in over a year — possibly abandoned
  3. Select folders to delete

    Use the checkboxes to pick individual folders, or use Select All / Deselect All. The Remove from Recent Documents checkbox (on by default) will automatically clean up Studio One's recent file list for any songs inside the deleted folders.

  4. Delete

    Click Delete. A confirmation dialog shows the folder count before anything is removed. Deleted folders disappear from the list immediately.

Right-Click Context Menu

  • Open in Explorer — browse the folder contents before deciding
  • Send To Archiver — loads the selected folder directly into Song Archiver and triggers analysis immediately
Deletion is permanent. Use Open in Explorer to inspect a folder before removing it, and ensure you have backups of anything important.

💾 Song Backup

Synchronises your song folders to a backup location by copying only new or changed files. Unchanged files are skipped, making each run after the first very fast.

  1. Select the songs root folder

    Click Browse next to "Songs folder" and choose the directory that contains your individual song subfolders. The list populates automatically with every subfolder that contains a .song file.

  2. Choose which songs to back up

    All songs are pre-selected. Uncheck any you want to skip, or use Select All / Deselect All to reset the selection.

  3. Set the backup destination

    Click Browse next to "Backup to" and choose (or create) a folder where the backups will be stored. Each song is backed up into a matching subfolder inside this destination.

  4. Click Backup

    The app compares your source files against the backup destination and builds a plan, then shows the Confirm Backup dialog.

  5. Review the Confirm Backup dialog

    The dialog lists each song and the number of files that will be copied. Use the checkbox to control unused audio takes:

    • Include unused audio takes from tracks (default: on) — all files are backed up, including WAV recordings not used in the mix.
    • Unchecked — WAV files not referenced by the song are skipped. File counts update live so you can see the difference before committing.

    Click Cancel to return to the selection screen, or Backup to start copying.

  6. Backup runs and completes

    A status message tracks progress as each file copies. When finished, a summary shows how many files were copied and lists any errors.

Both the songs folder and the backup destination are remembered between sessions — the next time you open Song Backup, both fields are pre-filled and the song list loads automatically.
Song Backup is additive only — it never deletes files from the backup destination. Files removed from the source will remain in the backup.

✏️ Song ReNamer

Renames an entire Studio One song package in one operation. The folder, matching .song files, Mixdown/Master audio files, and internal path references inside the .song archives are all updated automatically.

  1. Open the song folder

    Click Browse and select the Studio One song folder you want to rename. Analysis runs automatically — no extra button click needed.

  2. Review the analysis

    The panel shows:

    • The current folder name
    • A "Default name" badge if the folder still has Studio One's auto-generated Username_YYYY-MM-DD name
    • Suggestion chips for any .song files whose names differ from the folder name
    • A Play button if a Mixdown or Master audio file is found
  3. Optionally listen to the song

    Click Play Mixdown or Play Master to hear the latest export and confirm you have the right song open. Click Stop to end playback.

  4. Choose the new name

    Click any suggestion chip to fill in the New name field automatically, or type a name directly.

  5. Click Rename and confirm

    A confirmation dialog summarises what will change. The tool then:

    • Updates internal path references inside each .song archive
    • Renames .song files whose stem matches the old folder name
    • Renames Mixdown/Master audio files that start with the old name
    • Renames the folder itself
  6. Done

    A summary confirms how many files were renamed. The panel re-analyses the renamed folder automatically.

Suggestion chips come from .song files whose names don't match the Studio One default pattern. If you saved a version under a real title at any point, it will appear here as a one-click option.
Rename is permanent — there is no undo. Make sure you have a backup before renaming an important project.

🔧 Path Fixer

Studio One stores absolute file paths inside every .song file. When a song is moved or restored to a different location, those paths no longer match and Studio One cannot find the media files. Path Fixer detects and corrects this in one click.

  1. Select the .song file

    Click Browse and choose a .song file. Analysis runs automatically — the tool reads the stored path from inside the file and compares it to where the file actually is now.

  2. Review the path comparison

    The panel shows:

    • Stored path — where Studio One thinks the song is
    • Current path — where the file actually is
    • Paths to fix — the number of internal references that need updating

    If the paths already match, the status bar will say "Paths are correct — no fix needed."

  3. Click Fix Paths

    A confirmation prompt reminds you to back up the file first. Click Yes to proceed. The tool rewrites all file:// URLs across every XML file inside the .song ZIP, replacing the old path prefix with the new one.

  4. Done

    The tool re-analyses the file and confirms the paths are now correct. Open the song in Studio One — all media files will be found automatically.

Path Fixer runs automatically as part of the Un-Archiver workflow — you only need to use it manually when you've moved or copied a .song file outside of the normal archive/restore process.
Back up your .song file before fixing. Although the tool uses a safe temporary-file write strategy, it's good practice to keep a copy before any in-place modification.

⚙️ Settings

Access settings from the ⚙ icon in the Song Archiver window. Changes take effect the next time a field is auto-populated.

Setting Description Used by
Default Song Folder Pre-populates song folder fields and triggers automatic scanning on open. Song Archiver, Folder Sweeper, Un-Archiver (default destination)
Default Archive Folder Pre-populates the archive destination in Song Archiver. Song Archiver
Default Backup Folder Pre-populates the backup destination in Song Backup. Also saved automatically after a successful backup. Song Backup
Default Rename Folder Remembered automatically after each rename. The folder browser in Song ReNamer opens here by default. Song ReNamer
Debug Mode When enabled, archives include an XML schema discovery report (_DEBUG_Song_Schema.txt) and all raw XML files from the song archive. Useful for diagnosing parsing issues. Song Archiver
Settings are stored in %APPDATA%\StudioOneTools\settings.json. You can edit this file directly in a text editor if needed.

❓ Troubleshooting

Solutions for the most common issues.

"No .song files found in the selected folder"
Make sure you selected the song folder directly — the one that contains the .song file — not a parent directory that holds multiple songs.
"Referenced media file is missing"
One or more WAV files referenced by the song do not exist on disk. Open Studio One, locate the missing files using Pool → Find Missing Files, then re-analyse. Archiving is disabled until all referenced files are present.
All WAV files show as "not used" in the Archiver
This typically happens when the song has been moved from its original location and the internal paths no longer match. Run Path Fixer on the .song file, then re-open it in the Archiver.
"Could not find the stored song path (documentPath)"
The mediapool.xml inside the .song file does not contain a documentPath entry. This can happen with very old or manually edited song files. Open and re-save the song in Studio One to regenerate the entry, then try Path Fixer again.
Path Fixer shows "Paths are correct" but Studio One still reports missing files
The internal paths match the current location, but the media files themselves may have been moved or deleted. Check that the Media/ subfolder is present and contains the expected WAV files.
"A folder named X already exists at the destination" (Un-Archiver)
The Un-Archiver will not overwrite an existing folder. Rename or move the existing folder, or choose a different destination.
Analysis is slow on first scan
The first scan of a large song folder (many audio files) can take 10–20 seconds while the app opens and parses the .song ZIP archive. Subsequent scans of the same folder are faster due to OS-level disk caching.
The archive is larger than expected even with "exclude unused media"
A file is considered used if its use count in mediapool.xml is greater than zero. This is intentionally conservative — files that were once referenced may still be needed if you undo edits in Studio One.
Song Backup shows 0 files to copy
All files in the selected songs are already present and up to date in the backup destination. If you expected changes, confirm that you are pointing at the correct backup folder.
Song Backup skips a song folder entirely
Song Backup only lists folders that contain at least one .song file at the top level. Confirm the folder contains a valid Studio One project file.
Folder Sweeper flags folders I want to keep
Simply leave those checkboxes unchecked before clicking Delete. The Sweeper does not delete anything that is not explicitly selected and confirmed.
Song ReNamer shows no suggestion chips
Suggestions come from .song files whose names differ from the folder name and don't match the default Username_YYYY-MM-DD pattern. If all .song files use default names, type the new name directly in the New name field.
Song ReNamer "Rename" button stays greyed out
The button enables only when the new name is non-empty and different from the current folder name. Check that you haven't accidentally typed the same name, and that the new name contains no invalid characters (e.g. \ / : * ? " < > |).
Some files were not renamed after using Song ReNamer
Song ReNamer renames .song files whose stem exactly matches the old folder name, and Mixdown/Master audio files whose filename starts with the old name. Files with different names or in other subfolders are left unchanged by design.
